SEC EDGAR 서버 툴 유효성 테스트를 진행했다.
fetch multi quarters tool에서 4분기 값을 검색하지 못하는 문제가 발견되어 연간 보고서와 직전 보고서의 9개월 누적치를 이용해 4분기 단독 수치를 구하는 함수를 추가했다.
fetch multi years tool에서 NVDA 매출 수치가 잡히지 않는 문제 - 2022년까지 매출계정(RevenueFromContractWithCustomerExcludingAssessedTax)으로 한번 잡히면 이후의 변경된 매출계정(Revenue)를 잡지 못하는 문제를 수정했다. 
재실행 결과 수치를 원본과 수동 대조하여 정확성을 확인하였다.
